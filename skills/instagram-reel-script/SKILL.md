# Instagram Reel Script

Create an original script tied to a specific audience job and measurement objective.

## Workflow

1. Load account context and select one Matrix candidate.
2. If using a trend, cite the trend dossier and confidence. If using a reference Reel, use only the abstracted mechanisms from its reverse-engineering report.
3. Define promise, proof, payoff, CTA, target duration, and one primary metric.
4. Write a timecoded script with spoken line, on-screen text, visual action, shot change, sound event, and purpose for each beat.
5. Audit the first three seconds for immediate comprehension without false urgency.
6. Audit information density, pauses, shot rhythm, accessibility, and subtitle readability.
7. Provide two hook variants and one structurally different control for testing.

## Output

Return production-ready timecodes, assets, capture notes, edit notes, text-safe zones, caption, cover concept, hypothesis, counter-metric, and experiment ID.
