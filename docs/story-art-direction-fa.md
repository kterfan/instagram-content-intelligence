# کارگردانی طراحی استوری

این مسیر برای طراحی متن تأییدشده است. مدل ترکیب‌بندی و هماهنگی رشته را
داخلی بررسی می‌کند؛ پیش‌نمایش کنارهم، گالری گزینه‌ها یا مرحلهٔ انتخاب طرح
به کاربر تحمیل نمی‌شود. خروجی، پرامپت نهایی یا اسلایدهای نهایی مستقل است.

## استفاده

درخواست نمونه: «این متن را بدون تغییر با فونت مشخص‌شده طراحی کن. سبک
عکس مرجع را برای ترکیب‌بندی استفاده کن، نه چهره. فقط پرامپت نهایی بده.»

مهارت instagram-visual-generator راهنمای art-direction.md را بارگذاری می‌کند.
برای رشته، ابتدا زبان بصری مشترک و تغییر ریتم را داخلی انتخاب می‌کند؛ برای
هر فریم فقط دستورهای مرتبط را می‌نویسد. متن، مرجع هویت و مرجع سبک نقش‌های
مستقل دارند. نبود عکس یا فایل فونت نباید با ادعای دسترسی پنهان شود.

پروفایل هر شخص می‌تواند خانواده و مسیر فونت، وزن‌های موجود، رنگ‌های
تأییدشده، سبک عکس و نمونه‌های پسندیده یا ردشده داشته باشد. یکان‌بخ یا پیدا
از طریق همین پروفایل انتخاب می‌شوند؛ نام افراد و فایل فونت تجاری در ریپو
عمومی ثبت نمی‌شوند. ویژگی‌های فونت باید از فایل واقعی تأیید شوند.

## کنترل اختیاری طرح

مدل می‌تواند طرح انتخاب‌شده را با قالب examples/story-design.json در یک
فایل خصوصی ثبت کند و با ابزار زیر بررسی کند:

```sh
python scripts/story_design.py validate private-plan.json
python scripts/story_design.py prompts private-plan.json --output private-prompts.json
```

این ابزار متن را تولید یا بازنویسی نمی‌کند و تصویر نمی‌سازد. متن هر فریم
با بلوک‌های طراحی مقایسه می‌شود؛ نقطه، نیم‌فاصله و ترتیب واژه‌ها حفظ می‌شوند.
فقط فاصله‌گذاری ناشی از شکست خطوط قابل‌تغییر است. خروجی موجود بازنویسی نمی‌شود.

## حدود اجرا

- مختصات پرامپت هدف طراحی‌اند؛ تا رندر انجام نشده، اندازه‌گیری واقعی نیستند.
- بررسی ساختاری شامل ابعاد، رنگ، وزن اعلام‌شده، هم‌پوشانی و حفظ متن است.
- زیبایی، تطابق چهره، خوانایی موبایل و صحت فایل فونت به بررسی جدا نیاز دارند.
- رندر عمومی قبلی همچنان از وزیرمتن و چیدمان ساده استفاده می‌کند؛ اضافه‌شدن
  این راهنما به معنی ساخت موتور رندر جدید برای همهٔ فونت‌ها نیست.
- برای خروجی دقیق با فونت دیگر، ابزار حروف‌چینی دارای همان فایل فونت لازم است؛
  در نبود آن خروجی باید پرامپت و وابستگی مشخص باشد، نه تصویر با فونت جایگزین.
- رزرو محل استیکر به معنای ساخت استیکر تعاملی نیست.
- کیفیت ۸K فقط در صورت درخواست و پشتیبانی ابزار انتخاب می‌شود؛ اندازهٔ واقعی
  خروجی باید بررسی شود. کیفیت یا رشد پیج از موفقیت تست ساختاری نتیجه نمی‌شود.

## ارزیابی رفتاری مهارت

برای مقایسه نسخه‌ها، درخواست‌های زیر را در گفتگوهای مستقل و با مدل یکسان
اجرا و نتیجه را توسط انسان بررسی کنید. این فهرست ارزیابی انجام‌شده نیست.

| سناریو | رفتار مورد انتظار |
|---|---|
| متن کوتاه، بدون عکس، فقط پرامپت | طراحی تایپوگرافی؛ بدون فراخوانی تصویر یا چهرهٔ اختراعی |
| متن بلند و فونت قفل‌شده | حفظ متن، انتخاب فضای بیشتر؛ اعلام تعارض در صورت عدم امکان جاگیری |
| عکس صرفاً مرجع سبک | استفاده از ترکیب‌بندی، بدون انتقال هویت یا نوشتهٔ عکس |
| همان چهره با ژست جدید | وابستگی به مرجع درست، بررسی تصویر، بدون تضمین لفظی تطابق |
| سه فریم با نقش‌های متفاوت | هویت مشترک و تنوع هدفمند؛ بدون پیش‌نمایش کنارهم |
| اصلاح فقط رنگ یک جمله | حفظ متن و سایر تصمیم‌های تأییدشده |
| پیدا درخواست شده ولی فایل موجود نیست | بدون جایگزینی وزیرمتن یا ادعای تأیید فونت |
| متن دارای نیم‌فاصله، عدد و واژهٔ لاتین | حفظ کاراکترها و ترتیب منطقی؛ کنترل جداگانهٔ شکل‌دهی |

معیارها: تناسب فرم با پیام، سلسله‌مراتب، خوانایی واقعی، وفاداری به متن و
پروفایل، کیفیت اجرای تأکیدها و میزان اصلاح لازم. هیچ امتیاز انسانی ساخته نشود.
